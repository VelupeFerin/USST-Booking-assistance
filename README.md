# 概述
## 简介
这是用于预订USST运动场的辅助程序。目前可用于预订516校区和1100校区的次日的羽毛球场。可为每个账号设置任务。每个任务只执行一次，失败不补订，目标场次不可订亦不寻找其他场次。
## 使用条件
在windows系统上运行，需要关闭自动睡眠，或设置自动唤醒任务。（见后文）
运行环境：Chrome浏览器。
# 使用说明

程序运行时，电脑需要保持运行。可设置电脑关闭自动睡眠，或者设置自动唤醒任务。两者设置其一即可运行。

## 获取Cookies
### Cookies简介
Cookies用于在不需要他人账号密码的情况下登录他人账号。
### 获取他人的Cookies
把独立程序-get_ydmap-usst_cookies_file.exe发给他人，他人需要安装Chrome浏览器并按照提示操作即可得到“xxx.cookies”文件，之后他人需要把这个文件发给您。
### 导入Cookies
收到他人的cookies文件后，将其放到此程序的目录的Cookies文件夹中，导入就完成了。
## 订场任务设置
在BookingTaskList.txt文件中设置订场任务。每行一个任务，每个任务的格式为"人名 校区 场次表列 场次表行"。
例如："abc 516 5 6"将会使用"abc.cookies"订516号校区羽毛球馆 13:00-14:00 的 6号场。
每个任务都会订2票，剩余票数不足则视为失败。
## 启动程序
主程序为main.exe。启动后，当窗口存在时等待到特定时间并自动开始订场。
等待期间，电脑可以进入睡眠。但订场任务开始时，电脑需要保持活动。
