# 基本功能概述

使用selenium模拟浏览器操作，在此之上使用undetected_chromedriver提供隐蔽性

可多人同时预订。通过cookie配置多人账号。使用HTML页面使选定场地可视化

预订失败则寻找同一时间的其他场次预订。预订成功后，导出场地二维码

目前仅支持516和1100两个校区的羽毛球场
